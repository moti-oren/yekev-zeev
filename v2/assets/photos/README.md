# Personal winery photo library — 2026-11-23

site: the 13 recent photographs and nine existing `../har-adar-*.jpg` images.
The first three are featured; the other 19 appear in the expandable gallery.
Each image has a French, English and Hebrew caption and alt description in
`galleryPhotos` in `../../app.js`. The first three metadata entries match the
static French figures in `../../index.html`.

All imported files are unchanged originals. CSS thumbnails in the expanded
gallery use `object-fit: contain`; the viewer opens the full original image.

that these facilities belong to the winery. Paris photographs identify Paris.
